# pycon-site-public

This is a public repository for reporting issues related to [us.pycon.org](https://us.pycon.org).

The source code for the PyCon US website lives in a private repository ([PyCon/pycon-site](https://github.com/PyCon/pycon-site)). Because that repository is private, members of the public cannot open issues there directly. This repository exists so that anyone can report bugs, request features, or ask questions about the PyCon US website.

## How to Report an Issue

1. Check the [existing issues](https://github.com/PyCon/pycon-site-public/issues) to see if your issue has already been reported.
2. If not, [open a new issue](https://github.com/PyCon/pycon-site-public/issues/new) and include as much detail as possible:
   - A clear description of the problem or feature request
   - Steps to reproduce the issue (if applicable)
   - The URL of the page where you encountered the problem
   - Screenshots or screen recordings (if helpful)
   - Your browser and operating system

The PyCon US website team will review your issue and work on it in the private repository.

## Contact

For general questions about PyCon US, visit [us.pycon.org](https://us.pycon.org) or reach out through the official PyCon US channels.
